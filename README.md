# ALAMEDA — DISTRITQ

Landing page de alta conversão criada para Ariane Laurindo, com foco no pré-lançamento ALAMEDA, no DISTRITQ, em Alphaville.

## Desenvolvimento

Requisitos: Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

O projeto gera uma exportação estática em `dist/client` e está configurado para publicação na Vercel.

## Fontes principais

- [ALAMEDA — ARQOS](https://www.arqos.com.br/projects/alameda)
- [DISTRITQ — ARQOS](https://www.arqos.com.br/distritq)
